The Takeaway: Design Earns the Right to be Read

“Data integrity builds the truth, but quality and design build the bridge to that truth.”

  • Without Quality: Excellent data is dismissed as amateurish or suspicious.
  • Without Familiarity: Complex data induces anxiety and cognitive rejection.
  • Without Personal Intuition: The user lacks the raw confidence to act on your insights.

The “Hard” Metrics (The Baseline): Data Integrity, Source, and Intent are what data professionals focus 99% of their time on. They are required, but they are invisible if the user rejects the chart upfront.

The “Soft” Metrics (The Gatekeepers): Quality, Familiarity, and Personal Intuition act as the emotional and cognitive gatekeeper. If a chart looks unprofessional or unfamiliar, viewers experience friction and judge it as untrustworthy before they even read a single data point.

This is one of the easiest mistakes to make. We have a palette with six colors, so naturally we want to use all six colors.

Now every bar is bright, every card is competing for attention, and the audience has to decide where to begin.

Most of the time, color works better when we use less of it and reserve the strongest contrast for the point that matters most.

Here, I have made the decision for the audience of where to focus their attention.

library(shiny)

# 1. User Interface (UI) - Defines how the app looks
ui <- fluidPage(
  titlePanel("Basic Shiny App Example"),

  sidebarLayout(
    sidebarPanel(
      # Input widget: A slider to select number of bins
      sliderInput(
        inputId = "bins",
        label = "Number of bins:",
        min = 1,
        max = 50,
        value = 30
      )
    ),

    mainPanel(
      # Output placeholder: Displays the generated plot
      plotOutput(outputId = "distPlot")
    )
  )
)

# 2. Server Logic - Defines how the app calculates outputs
server <- function(input, output) {
  # Reactive expression to render the plot based on user input
  output$distPlot <- renderPlot({
    # Use built-in Old Faithful geyser data
    x <- faithful$waiting
    bins <- seq(min(x), max(x), length.out = input$bins + 1)

    # Draw the histogram
    hist(
      x,
      breaks = bins,
      col = "#75AADB",
      border = "white",
      xlab = "Waiting time to next eruption (in mins)",
      main = "Histogram of Waiting Times"
    )
  })
}

# 3. Combine UI and Server into an App
shinyApp(ui = ui, server = server)
